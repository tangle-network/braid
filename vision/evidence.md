# Evidence and limits

Checked 2026-10-07. Sources establish their advertised contracts or recorded results, not Braid integration or comparative superiority. Recheck before implementation decisions that depend on changing behavior.

## Braid baseline

[PR 126](https://github.com/tangle-network/braid/pull/126) and [PR 127](https://github.com/tangle-network/braid/pull/127) merged test cleanup, explicit task feedback, portable profile drafts, and observational runner advice. The [learning implementation](../src/app/profile-learning.ts) labels drafts `unmeasured`; [advice](../src/app/runner-advice.ts) forbids causal superiority claims from feedback alone.

The [retained live attempt](../artifacts/verification/profile-learning/live-advice-unavailable.md) failed routing authorization before any advice call. It proves neither advice quality nor cloud delegation. [Packaged UI evidence](../artifacts/verification/profile-learning/README.md) establishes the recorded interaction flow, not provider execution.

Braid pins its dependencies in [package.json](../package.json). Newer Runtime source has additional improvement and pursuit features; source availability does not establish publication, integration, or production proof. Reuse opportunities include [Runtime improvement](https://github.com/tangle-network/agent-runtime/blob/main/docs/improve.md) and [Discovery's recursive architecture](https://github.com/tangle-network/discovery/blob/main/docs/02-architecture.md).

## Capability and research references

| Source | Established fact | Consequence for the vision |
| --- | --- | --- |
| [Claude workflows](https://code.claude.com/docs/en/workflows) | Scripted fan-outs run while chat stays responsive. The ultracode keyword has input-origin restrictions. | Fleet size and responsive chat alone offer limited differentiation; generated keywords are not a portable capability API. |
| [Codex goals](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex) | Persistent goals have thread scope, lifecycle and budgets. | A goal does not by itself establish independent cloud scheduling or host recovery. |
| [Pi extensions](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/extensions.md) | Extensions add executable tools, commands and session behavior. | Pin and inspect executable resources; distinguish session state from external durable state. |
| [Pi Durable](https://earendil.com/posts/pi-durable/) | A separate experimental framework provides checkpointed tasks and recovery semantics. | It is not an automatic upgrade to Pi CLI or proof of a Tangle adapter. |
| [Deep Agents async workers](https://docs.langchain.com/oss/python/deepagents/async-subagents) | A conversational supervisor can manage remote workers; updating interrupts and restarts a run on its thread. | Compare real control semantics instead of equating names such as steer. |
| [Agent scaling study](https://research.google/blog/towards-a-science-of-scaling-agent-systems-when-and-why-agent-systems-work/) | Tested coordination methods had task-dependent gains and losses. | Keep solo baselines and charge coordination costs; its numerical results are not Braid forecasts. |
| [OpenAI math](https://github.com/openai/math) | Published results have different verification stages; unformalized work can contain issues. | Preserve the distinction between generated claims and verified results. |
| [Vals material candidates](https://www.vals.ai/blogs/room-temperature-magnetic-semiconductors) | Calculated candidates retain outstanding experimental checks. | Research operations must track validation beyond agent agreement. |
| [Co-Scientist](https://deepmind.google/blog/co-scientist-a-multi-agent-ai-partner-to-accelerate-research/) | A multi-agent research system generates and refines hypotheses with scientific collaborators. | Research orchestration already has strong substitutes; judge value by reproducible outcomes and scientist effort. |

These sources motivate the comparison. They do not establish exclusive novelty, demand, willingness to switch, or that Braid selects better strategies.
