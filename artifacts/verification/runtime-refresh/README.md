The initial live attempt used Runtime 0.308.0, Tangle Provider 3.6.5, and Sandbox 0.60.22. Its displayed `starting` state is the last admission snapshot, not a fresh observation at timeout. A separate diagnostic attempt with Runtime 0.309.0 also failed before recovery. That attempt exposed a capture bug: the diagnostic read internal envelopes instead of public RPC projections, so empty diagnostic fields do not establish empty upstream events. The corrected diagnostic records public canonical fields, opaque identity hashes, and snapshot sequence/revision; raw provider payloads remain redacted. A third run captured native evidence and established the unanswered permission described above. That finding does not retroactively establish the earlier runs' causes. The corrected permission responder then passed all ten recovery assertions through Braid, with the original 180-second phase deadline and 30-second hold. The final fresh-consumer proof then passed on Runtime 0.312.0, Provider 3.6.6, and Sandbox 0.60.27. This verifies retained cloud conversations; ordinary conversations still do not admit a supervised root.
