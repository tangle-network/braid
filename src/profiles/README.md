# Published profiles

Disco maintains the Discovery Operator. To refresh the bundled profile, take
`profiles/operators/discovery-operator.json` from Disco and update the source
header in [`discovery-operator.ts`](./discovery-operator.ts). Each resource's
source commit and digest travel with the profile. The [third-party notices](../../THIRD_PARTY_NOTICES.md#published-discovery-operator)
record the pinned revision, distribution authority and licenses.
